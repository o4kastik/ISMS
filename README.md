# Репозиторий документации СМИБ

## Назначение

Данный репозиторий предназначен для ведения документированной информации
системы менеджмента информационной безопасности (СМИБ).

Репозиторий используется для хранения политик, процедур, инструкций,
шаблонов и записей, а также для контроля изменений и версий документов.

## Структура репозитория

- `01-politika/` — политика информационной безопасности верхнего уровня.
- `02-chastnye-politiki/` — частные политики информационной безопасности.
- `03-procedury/` — процедуры и регламенты.
- `04-instrukcii/` — инструкции, шаблоны и чек-листы.
- `05-zapisi/` — шаблоны записей и подтверждающие документы.

## Порядок внесения изменений

1. Изменения документов выполняются в отдельной ветке.
2. Каждое изменение фиксируется отдельным коммитом.
3. Сообщение коммита должно содержательно описывать выполненное изменение.
4. Изменения основной ветки выполняются через запрос на слияние.
5. Перед слиянием изменение должно пройти проверку рецензентом.
6. Утверждённые редакции документов отмечаются тегами версии.
